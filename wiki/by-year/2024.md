## 🎯 重点方向

### 1. numlockw: Wayland/TTY NumLock 工具

[numlockw](../personal-projects/numlockw.md) 创建于 2024-07-21，定位为 Wayland/TTY 环境下的 `numlockx` 替代：

- 使用 evdev/uinput 控制 NumLock；
- 支持设备枚举、多设备操作、等待设备、pre-hook；
- 后续 2026 年进一步追踪到 Linux input/evdev 内核路径并推动 python-evdev PR #251。

### 2. TelegramFileUploader: CI 产物上传

[TelegramFileUploader](../personal-projects/telegram-file-uploader.md) 创建于 2024-03-04，提供 GitHub Action + CLI + Docker 形式的 Telegram 文件上传：

- 多文件分组上传；
- 上传进度和 message URL 输出；
- 用于构建产物、日志归档和发布通知。

### 3. Stack Exchange 高密度答疑

[Stack Exchange 深度分析](../deep-dive/websites/stack-exchange.md) 记录 2024 年 6 个回答，覆盖：

- Android NDK stripping（最高分 4）；
- Docker volume backup；
- WebP→GIF 色彩/帧处理；
- PowerShell、gRPC/protoc、ZFS backup 等。

### 4. Linux Wiki / ZFS 文档

[Linux Wiki 贡献分析](../deep-dive/websites/linux-wiki-contributions.md) 记录 2024-11-30 对 Arch Wiki ZFS 安装文档添加 `dnodesize=auto` 等优化配置。
