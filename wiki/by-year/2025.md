### 1. [modelcontextprotocol/servers] PR #3250 - 实现多进程安全通信

**基本信息**
- 🔗 **PR链接**: https://github.com/modelcontextprotocol/servers/pull/3250
- ⭐ **项目Stars**: 75,600
- 📅 **提交时间**: 2025-08-02
- ✅ **状态**: 已合并
- 🏷️ **标签**: `concurrency` `ipc` `typescript` `performance`
- 📝 **改动**: +320 lines, 6 files

**问题描述**

MCP Servers在多个进程间共享工具和记忆时存在数据竞争：

1. **并发场景**:
   - 多个AI客户端（VSCode、浏览器、CLI）同时运行
   - 每个客户端需要访问共享工具和记忆
   - 数据需要跨进程同步

2. **原有设计局限**:
   ```typescript
   // 原设计 - 基于文件的简单同步
   async syncTools() {
     const tools = JSON.parse(fs.readFileSync('./tools.json'));
     return tools;
   }
   ```
   
   缺点：
   - 频繁的文件IO造成性能瓶颈
   - 无法实时感知其他进程的变化
   - 缺乏标准化的IPC通信

**解决方案**

实现基于命名管道的跨进程通信系统：

```typescript
// src/common/ipc-manager.ts
import { createServer, createConnection, Socket } from 'net';
import { randomUUID } from 'crypto';
import { join } from 'path';
import { tmpdir } from 'os';

export class IPCManager {
  private server: any;
  private clients = new Map<string, Socket>();
  private messageHandlers = new Map<string, Function>();
  private readonly pipePath: string;
  
  constructor(serviceName: string) {
    // 使用系统临时目录创建管道文件
    this.pipePath = join(
      tmpdir(), 
      `mcp-${serviceName}-${randomUUID()}.sock`
    );
    
    this.initServer();
  }
  
  private initServer() {
    this.server = createServer((socket) => {
      const clientId = randomUUID();
      this.clients.set(clientId, socket);
      
      socket.on('data', (data) => {
        try {
          const message = JSON.parse(data.toString());
          this.handleMessage(message, socket, clientId);
        } catch (error) {
          console.error('Failed to parse IPC message:', error);
        }
      });
      
      socket.on('close', () => {
        this.clients.delete(clientId);
      });
    });
    
    this.server.listen(this.pipePath);
  }
  
  // 注册消息处理器
  public onMessage(type: string, handler: Function) {
    this.messageHandlers.set(type, handler);
  }
  
  // 发送广播消息给所有连接的客户端
  public broadcast(type: string, payload: any) {
    const message = JSON.stringify({ type, payload });
    
    for (const client of this.clients.values()) {
      client.write(message);
    }
  }
  
  private handleMessage(message: any, socket: Socket, clientId: string) {
    const { type, payload, id } = message;
    
    const handler = this.messageHandlers.get(type);
    if (handler) {
      Promise.resolve()
        .then(() => handler(payload, clientId))
        .then((result) => {
          // 发送响应
          if (id) {
            socket.write(JSON.stringify({
              id,
              result
            }));
          }
        })
        .catch((error) => {
          if (id) {
            socket.write(JSON.stringify({
              id,
              error: error.message
            }));
          }
        });
    }
  }
}
```

**技术亮点**

1. **高效IPC实现**:
   - 使用命名管道（Unix socket）避免TCP/HTTP开销
   - 基于消息类型的路由系统
   - 异步请求/响应模式

2. **数据同步机制**:
   ```typescript
   // 工具注册时自动广播
   class ToolRegistry {
     private ipc: IPCManager;
     
     constructor() {
       this.ipc = new IPCManager('tools');
       
       // 注册处理器
       this.ipc.onMessage('GET_TOOLS', () => this.getAllTools());
       this.ipc.onMessage('REGISTER_TOOL', (tool) => this.registerTool(tool));
     }
     
     registerTool(tool) {
       // 添加到本地注册表
       this.tools.set(tool.name, tool);
       
       // 广播给所有进程
       this.ipc.broadcast('TOOL_REGISTERED', tool);
     }
   }
   ```

3. **健壮性设计**:
   - 自动清理僵尸连接
   - 错误处理和重连机制
   - 临时文件管理（启动时清理旧管道）

4. **性能优化**:
   - 批量消息合并
   - 消息去重
   - 惰性连接（按需建立）

**问题描述**

LibreChat需要集成MCP内存功能，以实现对话历史的持久化和跨对话记忆：

1. **用户需求**:
   - 在多个对话中引用之前的信息
   - 存储关键事实和知识
   - 创建结构化笔记和摘要

2. **技术挑战**:
   - LibreChat基于React+Express架构
   - 需要与MCP内存服务器无缝集成
   - 保持UI/UX一致性

**解决方案**

设计了完整的MCP内存插件系统：

```typescript
// server/plugins/mcp-memory/index.ts
import { spawn } from 'child_process';
import path from 'path';
import { MCPClient } from '@modelcontextprotocol/client';

export class MCPMemoryPlugin {
  private memoryServer: any;
  private mcpClient: MCPClient;
  
  async initialize() {
    // 1. 启动MCP内存服务器子进程
    const serverPath = path.join(__dirname, 'node_modules', '.bin', 'mcp-memory-server');
    this.memoryServer = spawn(serverPath, [], {
      stdio: ['pipe', 'pipe', 'pipe'],
    });
    
    // 2. 连接到MCP服务器
    this.mcpClient = new MCPClient({
      process: this.memoryServer,
    });
    await this.mcpClient.connect();
    
    // 3. 验证MCP内存服务可用
    const healthcheck = await this.mcpClient.invoke('mcp-memory-service_check_database_health');
    if (!healthcheck.healthy) {
      throw new Error('MCP Memory service failed healthcheck');
    }
    
    return this;
  }
  
  // 存储记忆
  async storeMemory(content, tags = [], type = 'note') {
    return this.mcpClient.invoke('mcp-memory-service_store_memory', {
      content,
      tags,
      memory_type: type,
    });
  }
  
  // 语义搜索记忆
  async searchMemories(query, threshold = 0.7, limit = 10) {
    return this.mcpClient.invoke('mcp-memory-service_retrieve_memory', {
      query,
      similarity_threshold: threshold,
      limit,
    });
  }
  
  // 自然语言时间查询
  async recallMemory(query, n_results = 5) {
    return this.mcpClient.invoke('mcp-memory-service_recall_memory', {
      query,
      n_results,
    });
  }
}
```

前端集成:

```tsx
// client/src/components/Chat/MemoryPanel.tsx
import React, { useState, useEffect } from 'react';
import { useRecoilState } from 'recoil';
import { chatMemoriesState } from '../../state/memories';

export const MemoryPanel: React.FC = () => {
  const [memories, setMemories] = useRecoilState(chatMemoriesState);
  const [searchQuery, setSearchQuery] = useState('');
  const [isSearching, setIsSearching] = useState(false);
  
  // 搜索记忆
  const searchMemories = async () => {
    if (!searchQuery.trim()) return;
    
    setIsSearching(true);
    try {
      const response = await fetch('/api/plugins/memory/search', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
        },
        body: JSON.stringify({ query: searchQuery }),
      });
      
      if (response.ok) {
        const results = await response.json();
        setMemories(results);
      }
    } catch (error) {
      console.error('Failed to search memories:', error);
    } finally {
      setIsSearching(false);
    }
  };
  
  // 记忆卡片组件
  const MemoryCard = ({ memory }) => (
    <div className="p-3 border rounded mb-2 hover:bg-gray-50">
      <div className="flex justify-between items-start">
        <div className="font-medium">{memory.content.substring(0, 100)}</div>
        <div className="text-xs text-gray-500">
          {new Date(memory.created_at).toLocaleDateString()}
        </div>
      </div>
      <div className="mt-2 flex flex-wrap gap-1">
        {memory.tags.map(tag => (
          <span className="px-2 py-1 bg-blue-100 text-blue-800 text-xs rounded">
            {tag}
          </span>
        ))}
      </div>
    </div>
  );
  
  return (
    <div className="w-full p-4 border-l">
      <h3 className="text-lg font-medium mb-4">Memories</h3>
      
      {/* 搜索框 */}
      <div className="flex mb-4">
        <input
          type="text"
          className="flex-grow p-2 border rounded-l"
          placeholder="Search memories..."
          value={searchQuery}
          onChange={e => setSearchQuery(e.target.value)}
          onKeyDown={e => e.key === 'Enter' && searchMemories()}
        />
        <button 
          className="bg-blue-500 text-white p-2 rounded-r"
          onClick={searchMemories}
          disabled={isSearching}
        >
          {isSearching ? '...' : 'Search'}
        </button>
      </div>
      
      {/* 记忆列表 */}
      <div className="space-y-2">
        {memories.length > 0 ? (
          memories.map(memory => (
            <MemoryCard key={memory.id} memory={memory} />
          ))
        ) : (
          <div className="text-gray-500 text-center p-4">
            No memories found
          </div>
        )}
      </div>
    </div>
  );
};
```
