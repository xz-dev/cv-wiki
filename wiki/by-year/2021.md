## 🎯 重点方向

### 1. Python 自动化和 CLI 思维

后续个人项目（如 [AdGuardHome-LogSync](../personal-projects/adguardhome-logsync.md)、[TelegramFileUploader](../personal-projects/telegram-file-uploader.md)、[numlockw](../personal-projects/numlockw.md)）都延续了这一阶段的思路：

- 将重复任务封装成 CLI；
- 用 Python 做文件处理、网络 API、系统集成；
- 通过 pip/pipx/GitHub Action/Docker 分发。

### 2. Linux 与容器经验积累

从网站材料看，2019-2020 已经进入 Arch Linux、网络运维、Docker 深度探索；2021 年则开始把这些经验用于更工程化的工具和自动化脚本。

### 3. 技术问答与社区互动

[Stack Exchange 分析](../deep-dive/websites/stack-exchange.md) 记录账号活跃时间为 2021 至今。虽然高质量回答集中在 2023-2024，但 2021 是进入英文技术问答社区的开始。
